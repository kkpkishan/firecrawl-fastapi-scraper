================================================================================
API USAGE
================================================================================

BASIC REQUEST (No Nested Scraping):
curl -X POST "http://localhost:8000/crawl" \
  -H "X-API-Key: your-api-key" \
  -H "Content-Type: application/json" \
  -d '{
    "url": "https://example.com",
    "keyword": "exam"
  }'

WITH NESTED SCRAPING:
curl -X POST "http://localhost:8000/crawl" \
  -H "X-API-Key: your-api-key" \
  -H "Content-Type: application/json" \
  -d '{
    "url": "https://example.com",
    "keyword": "exam",
    "follow_nested_urls": true,
    "max_depth": 2
  }'

================================================================================
DATABASE SCHEMA
================================================================================

RESULTS TABLE:
- page_url: Source URL (web page or document)
- page_title: Title or filename
- content_snippet: Extracted content with context
- data_key: Pattern name (Date, Exam, Advertisement, etc.)
- data_value: Extracted value
- created_at: Timestamp

QUERY EXAMPLES:
-- Get all dates
SELECT data_value FROM crawl_results WHERE data_key = 'Date';

-- Get document extractions
SELECT * FROM crawl_results WHERE page_url LIKE '%.pdf';

-- Get exam information
SELECT * FROM crawl_results WHERE data_key = 'Exam';

================================================================================
SYSTEM ARCHITECTURE
================================================================================

WORKFLOW:
1. API receives request with follow_nested_urls=true
2. Firecrawl scrapes initial URL
3. Regex extractor finds patterns in content
4. Nested scraper extracts URLs from patterns
5. URLs categorized: web pages vs documents
6. Documents downloaded and text extracted
7. Web pages scraped (new crawl jobs)
8. Regex patterns applied to all content
9. Structured data stored in database
10. Process repeats for nested URLs (up to max_depth)

MODULES:
- regex_extractor.py: Pattern matching
- nested_scraper.py: URL extraction and categorization
- document_extractor.py: Document content extraction
- main.py: Orchestration and API endpoints
